Billing rules

The simulator calculates cost using elapsed runtime persisted in SQLite.

Compute₹/hour × accumulated running seconds ÷ 3,600
Storage₹0.10 per GB-month, prorated from creation until termination
StopPauses compute charges; retained storage continues to accrue cost.
TerminateEnds compute and root-storage accrual while preserving billing history.

These are simulator rules and sample prices, not AWS billing or exact AWS pricing behavior.
